# Value proposition

## Current value (honest)

**Confirmed:** Faster and less error-prone than paper for single-device split capture; simpler than learning a heavy race platform for a small session; works in a mobile browser.

## Commercial value hypothesis (Proposed)

Split Times helps small clubs and organisers capture trustworthy split/TT results without hiring chip timing or wrestling spreadsheets — at a price and complexity appropriate to club scale.

## Alternatives clubs use today

| Alternative | When it wins | Open question |
| --- | --- | --- |
| Paper + stopwatch | Tiny sessions, no tech | Can we beat reliability anxiety? |
| Spreadsheets | Post-hoc data entry | Can live capture + export win? |
| Professional chip timing | Large fields, official rankings | We should not compete head-on initially |
| General race software | Entries + payments + results sites | Can focused timing UX win on race day? |
| Free stopwatch apps | Single finish line only | Multi-stage + bib keypad is our wedge |

## Claims we must not make yet

- “Works fully offline with multi-device sync” — **not true today**
- “Club-ready multi-user SaaS” — **not true today**
- “Certified timing accuracy” — **Unknown** / not evidenced
