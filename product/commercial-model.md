# Commercial model

## Current

**Confirmed:** No billing, plans, trials, or licence enforcement. Effectively a free tool if you have the URL.

## Proposed MVP model

| Element | Proposal | Status |
| --- | --- | --- |
| Seller | Organisation subscription (club/organiser) | Proposed |
| Pricing shape | Monthly/annual club plan OR per-event fee | Unknown which wins — validate |
| Free tier | Limited local-only or single-event trial | Proposed |
| Seat model | Soft seats for organisers/timekeepers; athletes free viewers later | Proposed |
| Payment provider | TBD | Unknown |

## What must exist before charging

Priority order (see also commercial readiness audit):

1. Durable server-side storage + org account
2. Basic roles (admin / timekeeper)
3. Reliable race-day path + recovery story
4. Export
5. Terms + privacy policy
6. Support channel
7. Billing

## Non-goals for first revenue

- Marketplace
- Athlete premium subscriptions
- Hardware sales
