# Target users (commercial)

## Paying customers

**Proposed priority order:**

1. Local triathlon clubs
2. Athletics / running clubs
3. Small race organisers
4. Cycling clubs (TT-friendly)
5. Coaches / training groups (secondary)

## Operating users

| User | Needs |
| --- | --- |
| Club admin | Billing, members/access, season archive |
| Event organiser | Race setup, results publication |
| Timekeeper volunteer | Fast, reliable capture UI |
| Coach | Quick TT / session timing |
| Athlete | View personal results (later) |
