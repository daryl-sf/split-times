# Product Context

The durable product memory for Split Times (requirements, architecture notes, gaps, roadmap, ADRs, and agent guidance) lives on the orphan documentation branch:

**https://github.com/daryl-sf/split-times/tree/product-context**

Start at that branch’s [`README.md`](https://github.com/daryl-sf/split-times/blob/product-context/README.md).

## Important

- The **application source** (this default branch) remains the source of truth for implementation.
- The **product-context branch** is the source of truth for product understanding and planning.
- Intended standalone repository name: `daryl-sf/split-times-product-context` (see `HOSTING.md` on the product-context branch for promotion steps).

Do not treat product-context docs as a substitute for reading the code when changing behaviour — and do not change behaviour without updating those docs when they are affected.
