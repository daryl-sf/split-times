# Commercial readiness

## Verdict

**Not ready to sell** as a professional club product. Ready to **learn from real users** as a free/single-operator tool while Stabilise work lands.

## Assessment by capability

| Capability | Needed for first paid release? | Current | Priority |
| --- | --- | --- | --- |
| Multi-tenancy / organisations | Yes | Missing | Critical |
| User management | Yes | Missing | Critical |
| Roles / permissions | Yes | Missing | Critical |
| Security basics | Yes | Missing | Critical |
| Privacy policy / terms | Yes | Missing | High |
| Data ownership clarity | Yes | Device-only | Critical |
| Data export | Yes | Clipboard only | High |
| Data deletion (org-level) | Yes once PII/server | Admin wipe local only | High |
| Backups | Yes | Missing | Critical |
| Reliability story | Yes | Partial single-device | Critical |
| Monitoring | Soft for MVP | Missing | Medium |
| Support channel | Soft for MVP | Missing | High |
| Billing / subscriptions | Yes to charge | Missing | Medium (after core) |
| Onboarding | Soft for MVP | Missing | High |
| Documentation (customer) | Soft for MVP | Missing | High |
| Audit logs | Nice for MVP | Missing | Medium |
| Ops admin | Nice | Missing | Medium |

## Minimum path to first revenue (Proposed)

1. Finish Stabilise (`roadmap/now.md`)
2. Ship org + auth + durable races + export + policies (`roadmap/next.md`)
3. Pilot with 1–3 friendly clubs at discounted/paid pilot rates
4. Only then harden billing and multi-device

## What not to wait for

- Chip integrations
- Native apps
- Full category/federation features
